## 📌 About The Project

This is a browser-based implementation of the classic **Stone–Paper–Scissors** game.
It focuses on strengthening **core JavaScript concepts** like:

* DOM Manipulation
* Event Handling
* Conditional Logic
* Randomization

The project is designed to simulate real-time interaction between a user and the computer.

---

## ✨ Features

* 🎯 Interactive gameplay
* 🤖 Random computer moves
* ⚡ Instant result display
* 📊 Live score tracking
* 🎨 Clean UI with responsive layout

---

## 🧠 Game Logic

| Player   | Computer | Result |
| -------- | -------- | ------ |
| Stone    | Scissors | Win    |
| Scissors | Paper    | Win    |
| Paper    | Stone    | Win    |
| Same     | Same     | Draw   |
